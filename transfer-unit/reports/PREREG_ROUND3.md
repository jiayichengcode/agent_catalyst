# 预注册 第三轮:高 seed 决胜实验(2026-08-29,启动前落盘)

## 为什么需要这一轮
前两轮的速度差异被证明处于 seed 噪声内(tt@0.7 的 seed 间离散达 6-7 倍;
AUC 离散 0.17-0.33 ≈ 条件间差异)。此外发现两个必须修正的方法学问题:
1. **总 token 口径**:掺 C 后在同一 B-token 处已多走优化步。总轴换算后多数加速消失,
   "多加自己数据"(b90k)的基线是 1.7×,而非 1.0×。
2. **checkpoint 采样偏差**:save_every 按优化步计,掺 C 多的条件在 B-token 轴上采样更密,
   系统性偏向更早的穿越点。本轮按混合比例调整 save_every,使各条件的
   **B-token 采样间隔相等**(none/b90k SE=2, mh15 SE=3, pyf60 SE=6)。

## 设计
4 条件 × 8 seeds = 32 runs,eval n=48(降低测量噪声)
| 条件 | B | C | 角色 |
|---|---|---|---|
| none | 30k | — | 欠训练基线 |
| b90k | 90k | — | **预算对照**(多加自己的数据) |
| mh15 | 30k | hard math 15k | 亚化学计量催化(最像催化剂的点) |
| pyf60 | 30k | pyfix errrec 60k | 前两轮观测最快 |

## 预注册判读(主指标 AUC,次指标总轴 tt@0.7,均报 8-seed 分布)
- H1 催化存在:mh15 或 pyf60 的 AUC 分布**显著高于 b90k**(Mann-Whitney p<0.05)
  → 存在超出预算效应的真实催化
- H0 只有预算效应:三者与 b90k 无显著差异,但都高于 none
  → 结论为"任何额外数据都能改善欠训练,内容无关",催化剂概念在此设定下证伪
- 若 mh15(仅 +15k token) 与 b90k(+60k token) 打平 → 仍有实用价值(等效收益、1/4 数据量),
  但机制归于"数据量",不是催化

无论结果如何如实报告;本文件在训练启动前落盘。
