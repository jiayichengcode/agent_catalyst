## 2. 判读(对照预注册规则)

观察到的排序:**noC ≈ F3 > F6 > F5**。

1. **迁移效应存在,但符号为负**:等 token 预算下,C 的梯度拖慢 B(F6 vs noC:AUC 0.673 vs
   0.785,tt@0.8 147 vs 75)。这对构造对是"干扰对"而非"加速对"。
2. **G2(轨迹级承载)方向性成立,且是全文最有价值的发现**:F3 与 F5 是完美受控对比
   (同 token 预算、同超采样结构、同实例多样性,唯一差异=轨迹内容),结果天壤之别——
   **只保留 err_recovery 轨迹时干扰完全消失(F3≈noC),等量随机轨迹时干扰最大化(F5 最差)。
   跨任务效应的载体确实在轨迹层,不在任务层。**
3. 附带发现:F6 的全量 C 梯度让 C 自身的 eval 都剧烈失稳(pyfix 曲线两次深跌),而 F3 的
   err_recovery-only 梯度下 C 平稳——"哪些轨迹进梯度"同时影响本任务稳定性与跨任务干扰。
4. 对 RFT 惯例的含义(待 F1 证实):若 F1(仅成功)介于 F3 与 F6 之间,说明"success-only"
   保留了一部分干扰载体(无报错成功轨迹);若 F1≈F3,干扰主要来自失败轨迹。

**机制假设(待 F0 判别)**:干扰经由梯度通道(而非 rollout 分布)。预测:F0(C 只交互不学习)
≈ noC。若成立,故事定型为"轨迹内容决定跨任务梯度干扰,err_recovery 轨迹是无害/有益子集,
过滤器可以在保留多任务混合的同时消除干扰"。

## 3. 已知局限(诚实清单)
- 单 seed、单任务对、B eval n=48(SE≈0.07)。曲线级排序稳定(AUC/tt 多指标一致),但
  需 3 seeds 才能做显著性宣称。
- F5 截断在 83 步(重跑中);其 ≤80 步的差距(-0.27 vs F3)远超噪声带。
- 归一化/基线等 4 个方法学修复只在 v6 生效,v3-v5 数据全部作废(见 EXPERIMENT_BRIEF)。
- "催化剂"预期符号未出现:这对任务里 B 自学能力太强(task 基线让 B 每步都有充足自梯度),
  可能压缩了正向加速的空间;正向加速对可能需要 B 更难/更稀疏奖励的设置——这是 phase-3 的
  自然实验(调 B 难度扫描迁移符号翻转点)。

## 3.5 SFT 催化线(2026-08-26,seed 修复后,数据干净)

概念转向(用户指正):真催化剂 = 与目标数据**同批参与同一个 loss**并帮助目标学习——原生舞台是
SFT/预训练;RL 的 GRPO 组内优势结构上隔离了催化数据(但 RL 有独有的"点火"通道:C 梯度改变
策略→改变 B 的 rollout 分布)。两条线并行。

**SFT 第一轮**(260k B 成功 token,±230k C-errrec token,vs 基线 sql 0.667/pyfix 0.583/neutral 1.0):
| 条件 | sql 贪心 | pyfix | neutral |
|---|---|---|---|
| B-only | **1.000** | 0.417⤵ | 0.500⤵⤵ |
| B+C-errrec | 0.958 | 0.542 | **1.000** |
- B 剂量太大直接打满 → B 上无催化余量;
- **意外发现:C 数据是遗忘保护剂**——B-only SFT 摧毁 neutral 格式能力(1.0→0.5)与 C 能力
  (0.583→0.417),混入 errrec 后两者完好。auxiliary-data-as-regularizer 的干净证据。
**剂量-响应扫描完成**(sql 贪心 pass@1,n=48,SE≈0.07;基线 0.667):
| B token | B-only | +C-errrec(230k) | +C-random(230k) |
|---|---|---|---|
| 30k | 0.583 | 0.792 | **0.896** |
| 90k | 0.688 | 0.896 | **0.917** |
三个结论:
1. **催化效应大且稳健**:两个剂量下 +C 都比 B-only 高 0.21-0.31(≈3-4 SE);B-only 的
   成功轨迹自蒸馏本身表现平平甚至负收益(0.583/0.688 ≈ 基线上下)。
2. **内容非特异**:random(含 54% 失败轨迹)≥ errrec——SFT 里的催化机制不是"错误恢复技能
   注入",更像**分布多样性/抗塌缩正则**:C 数据阻止 B-only 蒸馏把策略压进窄而脆的模仿分布。
3. 副证:B-only 摧毁 pyfix(0.375)与 neutral 部分退化;errrec 条件顺带把 pyfix 提到 0.792。
**关键对照已出(修正机制解释)**:
| 对照 | sql 贪心 | 含义 |
|---|---|---|
| b30_rep9(30k B×9 epoch=270k,总量对齐) | 0.771 | **催化收益大头=训练量效应**:B-only 重复训练即接近 +C 水平,净催化余量缩至 +0.02~0.12(单 seed 内不可判) |
| b30_bfail(B 自己的失败轨迹 230k 当催化剂) | **0.333** | **同任务失败轨迹是毒药**(0.667→0.333)——"多样性万能"被否;跨任务失败轨迹(random 中 54%)则无毒。内容作用不对称:毒性同任务特异,益性跨任务泛化 |
在跑:s2 复制(none/random)、spanmask(span 级去咖啡因)、rep9rand(270k B + 230k C,
彻底分离"总量"vs"内容"——最锐利的一刀)。

**RL 侧 curriculum 判别(hard2_seq)已出前段**:纯 C 训练 50 步(pyfix 打到 0.958),B 全程
0.000;切纯 B 后 20 步仅 0.321,而 noC 从零 20 步已 0.750——**顺序课程是负收益**,
"先学 C 再学 B"比什么都不做更糟(纯 C 阶段的策略特化损伤了后续可塑性)。
