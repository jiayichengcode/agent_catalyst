# 预注册 第四轮:毒药结论在第二个目标任务上的复现(2026-09-01,启动前落盘)

## 为什么是这一轮
Round 3 判定"催化剂"不成立后,唯一通过全部对照的效应是 **同任务失败轨迹是毒药**
(原始观测:B=sql_query,掺入 sql 自己的失败轨迹 230k → 0.33/0.56,基线 0.72)。
它量级大、与常见实践冲突(不少 rejection-sampling 流水线为"多样性"保留失败轨迹),
但**只在一个目标任务上测过**,且没有区分"毒性来自同任务"还是"毒性来自失败本身"。
本轮换 B=codegen 复现,并把这两个解释拆开。

## 设计:2×2(极性 × 来源),两格已在库
B = codegen · 30k 目标 token · eval codegen n=48 · 主指标 = pass@1 曲线 AUC

| 条件 | C 来源 | C 极性 | C token | n | 状态 |
|---|---|---|---|---|---|
| `r3_none` | — | — | 0 | 8 | **已在库** |
| `r3_pyf60` | pyfix(跨任务) | 错误恢复 | 60k | 8 | **已在库**(AUC 0.719) |
| `r4_pyfail60` | pyfix(跨任务) | **失败** | 60k | 8 | 本轮 |
| `r4_cgfail60` | codegen(**同任务**) | **失败** | 60k | 8 | 本轮 |

- `r4_pyfail60` vs `r3_pyf60`:同任务来源、同剂量,**只差极性** → 检验"区别在是否恢复"。
- `r4_cgfail60` vs `r4_pyfail60`:同极性、同剂量,**只差来源** → 检验"区别在是否同任务"。
- checkpoint 间距:两个新条件 C/B = 2.0,`save_every=6`,与 `r3_pyf60` 一致,
  保持 Round 3 的修正(各条件在 **B-token 轴**上采样间隔相等)。
- `--c-skip-b` 全程开启:`cgfail60` 的 C 池与 B 训练集**实例不重叠**,
  且 B 恒定只装成功轨迹(`sel=b_success`),不存在同一条轨迹既在 B 又在 C。

## 预注册判读(Mann–Whitney,AUC,双侧)
- **P1 毒药复现**:`cgfail60` 显著低于 `r3_none`(p<0.05)
  → 同任务失败轨迹在第二个目标任务上仍是毒药,结论跨任务成立。
- **P2 跨任务失败无害**:`pyfail60` 与 `r3_none` 无显著差异(p>0.05)
  → 毒性来自"同任务",不来自"失败"本身。
- **P3 极性是关键**:`pyfail60` 显著低于 `r3_pyf60`
  → 即便跨任务,失败与恢复也不等价;"区别不在是否出错,而在是否恢复"成立。

**四种结果的读法(事前写死)**
| cgfail60 | pyfail60 | 结论 |
|---|---|---|
| < none | ≈ none | **主假设成立**:毒性 = 同任务 × 失败。可写论文 |
| < none | < none | 毒性来自**失败本身**,与来源无关 → 原"跨任务失败无害"被推翻,改写叙事 |
| ≈ none | ≈ none | **不复现**。可能是任务特异,或剂量特异(原始 230k,本轮 60k)→ 必须补 230k 剂量臂再定案,不得直接宣告否证 |
| ≈ none | < none | 反直觉(跨任务比同任务更毒),优先怀疑数据生成或标注错误,先查 donor 构造 |

## 剂量说明(事前声明,防止事后找补)
原始毒药观测在 **C=230k**(C/B≈7.7),本轮为 **60k**(C/B=2.0),剂量低约 3.8 倍。
选 60k 是为了与已在库的 `r3_pyf60`/`r3_none` 严格可比(同预算、同 checkpoint 间距)。
**因此"cgfail60 ≈ none"不构成对原结论的否证**,只说明该效应在低剂量下不显著;
该情形下的后续动作已在上表写死(补 230k 臂)。
