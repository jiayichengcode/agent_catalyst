# 文献综述 II:"用梯度几何预测/解释训练加速"这个方向有人做吗?(2026-08-28)

**结论:三块拼图各自都有厚实文献,但把它们拼成"用梯度秩几何事前预测辅助数据的加速倍数"
——没有找到。这是目前为止最干净的空位。**

## 拼图 1:梯度低秩动力学(基础设施成熟,动机完全不同)

- **训练中梯度秩单调下降,渐近趋于 rank-1**(AdaRankGrad 2410.17881 的核心观测;
  Emergent Low-Rank Training Dynamics 综述)。
- GaLore 系 / **AdaRankGrad** / **SubTrack++** / **SUMO**(2505.24749) / **Fira** / **WeLore** /
  Taming Momentum(2602.24283):把梯度投影到低秩子空间以**省显存**;
  Fira 发现"Adam 的逐矩阵缩放因子在低秩投影下几乎不变"。
- **动机全是内存效率**,不是"数据选择"或"加速预测"。**没人把秩当作数据的属性去比较不同数据源**。
- 但它给我们的理论提供了关键支撑:**秩塌缩是训练的固有趋势**,
  这正是"催化剂补充秩"能起作用的前提。

## 拼图 2:多任务梯度冲突(方向问题,不是秩问题)

PCGrad(NeurIPS 2020)、CAGrad(2021)、ConicGrad(2502.00217)、MetaBalance、Sample-Level
Weighting——全部围绕**冲突梯度**(cos<0)做手术;判据是**成对余弦**。
**与我们的发现正相反**:我们测到的催化数据 cos≈0.01-0.05(既不冲突也不对齐),
按 PCGrad 系的框架属于"无关紧要"的区间——而它恰恰是加速最强的区间。
**"近正交但同参数空间的梯度能加速"这个现象,冲突文献没有覆盖。**
另有 The Effect of Training Task Diversity on ICL through Low-Dimensional Subspaces
(2606.06814):任务多样性加速 transformer 收敛,给出梯度流分析——**理论上最接近的一篇**,
但它在 ICL/合成设定下,不做数据选择,也不预测具体数据的加速倍数。

## 拼图 3:预测训练结果 / 数据选择(预测终点,不预测速度机理)

- **TuneAhead**(2606.17660):早停外推预测微调**最终性能**;
  假设"初期 loss 下降速度预示最终收敛"——**用速度预测终点**,与我们**用几何预测速度**相反。
- **Gradient Consistency**(相邻梯度余弦):高一致=快收敛(与我们的秩视角互补但不同量)。
- **GradFiltering / Uncertainty-Aware Gradient SNR**(2601.13697):用梯度信噪比选数据,
  报告"选出的子集收敛更快"——**最近的实用近邻**,但①在**同一数据集内**选样本,
  不做跨任务催化;②用 SNR 不用秩;③不建立可外推的预测判据。
- Layer-Aware Influence(2510.16007)、LoRA-GA(梯度近似初始化)、GRADE(2604.02830,
  用梯度子空间动力学探测知识缺口)——都在用梯度几何做诊断,但目标不是加速。

## 我们的空位(精确表述)

1. **因变量**:time-to-τ(达到目标水平所需**目标任务** token),而非终点质量。
   跨域/配比文献(见 LIT_REVIEW_catalyst.md)几乎全测终点;TuneAhead 把速度当**预测器**而非**被解释量**。
2. **自变量**:辅助数据的**梯度秩几何**(rank_gain、cos_within_C、弱耦合窗口 cos_BC),
   在**训练开始前**即可算出。低秩优化文献有工具无此用法;冲突文献只看方向不看秩。
3. **可证伪的判据**:rank_gain>0 且 cos_BC∈(0.005,0.10) → 预测 ≥2.5× 加速。
   已预注册 out-of-sample 检验(reports/PREREGISTERED_PREDICTION.md,训练进行中)。
4. **现象学**:掺料普遍 2.4-30× 加速而"加更多目标数据"只有 1.7×;
   微量(0.5×B)即达最大加速;加速与终点解耦——这组事实本身在文献中没有系统报告。

## 风险与需要引用的最近邻
- 若判据只是"任务多样性有益"的重述 → 2606.06814 会被审稿人拿来压;
  区别在于我们给**具体数据集**算**具体数字**并做**外样本预测**,他们做的是渐近理论。
- GradFiltering 的"收敛更快"结论必须显式对比:它是同域选样本,我们是跨域选数据源。
- 低秩优化文献需在 related work 里说明:我们借用它们的**观测**(秩塌缩),
  但用途相反——它们压缩秩省显存,我们**补充秩**换速度。
