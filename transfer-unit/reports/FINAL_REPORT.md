## 2. 六个结论(按证据强度排序)

1. **[强] 同任务失败轨迹是毒药**:两 seed 0.333/0.562,远离其余全部 27 个 seed 点。
   蒸馏时绝不能把自己任务的失败混进去。
2. **[强] 训练量是第一因子**(用户的规模质疑被数据裁定为正确):30k 欠训练(0.715)是主要短板,
   同预算三方——掺催化剂 0.806 ≈ 收 3 倍自己数据 0.806 ≈ 重复 3 epoch 0.778——**随机内容的
   "净催化"在规模控制后消失**。
3. **[强] 无关数据不是安全填充**:neu230 均值 0.694 ≤ none——高剂量无关 token 轻度有害,
   "掺什么都行"彻底否定。
4. **[中] 精选错误恢复轨迹是唯一跑赢预算控制的内容**:errrec230 均值 0.854,领先 b90k/py60
   +0.05,独占全实验前二单点(0.958/0.896);但 s3=0.708 使带重叠——建议追加 seeds 与
   剂量点(errrec60)定案。若坐实,故事= **"催化剂真实存在,但必须提纯:有效成分是错误恢复
   轨迹,粗提物(随机轨迹)只有预算效应"**——与原 research plan 的 F3 直觉在 SFT 舞台复活。
5. **[中] 域距离衰减**:近域随机(0.806@90k)≥ 远域(0.785@260k, 0.708@90k)> 无关(0.694)。
6. **[强,RL 侧] RL 无催化位点**:GRPO 优势隔离 + on-policy 数据自多样;混训中性,
   顺序课程只有点火税(先练满 C 再学 B 反而慢 20 步)。催化剂是离线蒸馏特有现象。

## 3. 实操配方(给工程团队的一段话)
蒸馏 agent 能力时:①先保证目标任务数据量/epoch 充分(欠训练是最大坑);②绝不混入目标任务
失败轨迹;③不要用无关数据凑量;④若目标任务数据贵,近域任务的轨迹可等效替代约 2/3 的目标
数据量;⑤最有希望的增益来自**筛选辅助任务的错误恢复轨迹**(待最终坐实)。

## 4. 方法学教训(论文方法节,全部有数据)
seed 碰撞伪采样 / 端点评测 ±0.2 方差(排序可反转,单 seed data-mixing 消融不可信)/
归一化分母混淆 / 难度筛选赢家诅咒(k=8 的 0/8 标签≈30% 假阳性)/ 逐 checkpoint 热载评测
(约 2.5 分钟/点)是让曲线网格可负担的关键基建。

## 6. 终判决(2026-08-27 追加:sqlerrrec 对照闭环)

用户质疑"同任务 errrec 是否也行"→ 直接实验(B30k + 去重 sql err_recovery 230k, 实例级防泄漏):
**0.854 / 0.854 / 0.875,均值 0.861,全实验最紧高位带。**

260k 预算层内对比:sqlerrrec 0.861(紧)≈ errrec-pyfix 0.854(宽)>> py230 随机 0.764
(**带完全分离**)> neu230 0.694。

**机制定案**:①催化有效成分=错误恢复轨迹(报错→修正→成功闭环),**来源任务无关**;
②随机轨迹稀释药效(同源同预算差 0.10,带分离);③失败轨迹单独喂=剧毒——**关键不在出错,
在恢复**。与 research plan 的 F3 假设闭环:err_recovery 确是特殊承载单元,舞台在 SFT 蒸馏。

论文定题:*The Active Ingredient: Error-Recovery Trajectories Catalyze Agent Distillation*。
